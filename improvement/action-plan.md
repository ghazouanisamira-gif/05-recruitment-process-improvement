# Recruitment Improvement Action Plan

## Improvement Logic

Actions should be linked to validated causes and managed through measurable ownership.

| Improvement Area | Expected Outcome | Owner | Priority | KPI | Control |
|---|---|---|---|---|---|
| Process standardization | Reduce variation | | High | Process compliance | Periodic review |
| Role clarification | Improve accountability | | High | Action closure | Governance review |
| Candidate tracking | Improve visibility | | High | Funnel conversion | Dashboard |
| Selection criteria | Improve hiring quality | | High | Early attrition | Quality review |
| Recruitment / Operations alignment | Improve workforce readiness | | High | SLA compliance | Weekly review |
| KPI implementation | Improve decision-making | | Medium | KPI availability | Monthly review |
| Control routines | Sustain gains | | Medium | Performance trend | Escalation |

## Prioritization Questions

- Does the action address a validated cause?
- What outcome should change?
- Who owns implementation?
- What is the expected time to impact?
- How will effectiveness be measured?
- What happens if the KPI remains below target?

## Control Logic

Every significant action should have:

**Owner + KPI + Review Frequency + Trigger + Response**

## Sustainability

Improvement is considered embedded when:

- the process owner can operate it without project support
- KPIs are reviewed routinely
- deviations trigger defined responses
- lessons learned are incorporated into the process
